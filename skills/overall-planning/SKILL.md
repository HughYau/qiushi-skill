# 统筹兼顾

> "把国内外一切积极因素调动起来。" —— 《论十大关系》

平衡不是"各方都少一点"的和稀泥，而是让各方面都发挥作用的配置；平衡点随条件变化而动。

## 用 / 不用

用：
- 多个相互制约的目标要权衡
- 优化一个维度时损害了另一个
- 多个利益相关方要协调
- 发现自己正片面追求某一目标

不用：
- 只有一个目标维度
- 用户已明确取舍方向
- 大方向已定、只需集中推进 → `concentrate-forces`
- 硬性二选一，没有动态平衡空间 → `contradiction-analysis` 定性后取舍

## 操作规程

1. **列辩证关系对**：本任务中真正存在的对立面（速度↔质量、深度↔广度、短期↔长期、简单↔灵活、探索↔稳定、集中↔分散……），按实际识别，不照搬模板。
2. **片面性检查**：当前方案是否完全忽略了某一方？是刻意取舍（可接受，写明）还是无意忽略（要纠正）？
3. **定当前阶段的平衡点**：每对关系一个侧重方向 + 另一方的底线。
4. **系统影响检查**：加强 A 会对其他关系对造成什么？连锁调整。
5. **学他人教训**：类似场景里因片面追求而失败的案例是什么？借鉴不照搬。
6. **设失衡预警**：出现什么信号说明失衡，需要重新平衡。

## 输出模板

```
辩证关系：
1. [A] ↔ [B]：目前偏向 [A / B / 均衡]，程度 [轻微 / 明显 / 严重]，属 [刻意取舍 / 无意忽略]
2. ……

平衡方案：
[A] vs [B]：当前阶段优先 [A]，但 [B] 不低于 ……；原因 ……

系统影响：加强 [A] → 对 [C]↔[D]：加剧 / 缓解 / 无影响，需 ……
失衡预警：若出现 ……，说明 [A]↔[B] 失衡，重新调用本 skill
```

## 纪律

- 禁止固定折中：平衡点必须与当前阶段条件挂钩。
- 禁止调整一处不看全局。
- 只写真实存在的关系对；凑数的关系对是形式主义。

## 交接

- 识别关系对本身就是矛盾分析 → `contradiction-analysis`
- 大方向定了 → `concentrate-forces` 执行
